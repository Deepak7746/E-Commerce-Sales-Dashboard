# E-Commerce Sales Dashboard 📊

An interactive E-Commerce Sales Dashboard developed using Microsoft Excel to analyze sales performance, profitability, customers, products, and regional performance.

## 📌 Project Overview

This project provides a visual analysis of e-commerce sales data through an interactive Excel dashboard. It helps identify key sales trends and business insights.

## 📊 Dashboard Features

- Total Sales
- Total Profit
- Sales by Product
- Sales by Customer
- Sales by Region
- Product-wise Sales Analysis
- Customer-wise Sales Analysis
- Interactive Filters and Slicers
- Pivot Tables and Pivot Charts

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Visualization

## 🎯 Objective

To transform raw e-commerce sales data into an interactive dashboard that makes business performance analysis easier and supports data-driven decision making.
